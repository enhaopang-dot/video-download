## 这是什么

一个统一的「这个链接怎么存下来」的入口。

不是万能解析器，是**各平台各走哪条路**的实战记录——哪条链路能跑、哪条会被拦、拦了怎么办。

## 覆盖平台

抖音 / 快手 / 小红书 / B站 / 微博 / 视频号

## 内容

- **已验证的下载链路**：每个平台用哪种方式、什么参数
- **反爬拦截判据**：怎么判断是被拦了还是链接失效
- **下载后的处理**：转正（m3u8 合并）、压缩（ffmpeg 参数）
- **实测参数**：码率、分辨率、体积的对应关系

## 一条重要结论

**反爬是 IP 级的，不是补丁级。**

实测发现：加了全套反检测补丁仍然被拦，因为判定维度里包含 IP 与频率。所以自动重试没用，**一次失败就该停手等冷却**，否则会拖累你在同一网络下的正常操作。
